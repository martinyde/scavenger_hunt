Internal · Design only

A shared visual language for Scavenger Hunt.

This site is a static playground for mocking up how the three Symfony apps — Archive, Admin, and the Race display — should look and feel. Approved designs are ported by hand into the real Twig templates afterwards; nothing here ships to production directly.

A

Archive

Public-facing catalogue of hunts. Browse, search, preview before running a race. Shop-like feel.

B

Admin

Internal tooling for editing hunts and managing races. Dense, structured, keyboard-friendly.

C

Race display

Participant view at the venue. Themeable — variables under [data-theme] drive colors, fonts, and radii.

How navigation works

The top tabs use a hash router (#/archive, #/admin, …). Each mock site can also be opened directly as a standalone HTML file — handy when reviewing one screen at a time in isolation.

How theming works

The race display reads its colors and typography from CSS custom properties scoped under [data-theme="…"]. Adding a theme is one CSS file plus one picker entry — see the race-display mock.
